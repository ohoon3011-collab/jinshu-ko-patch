# 금서군협전 한국어 자동 패치

금서군협전 FIX146용 한국어 패치와 자동 업데이트 배포 저장소입니다.

## 사용 방법

1. 최초 배포 ZIP을 게임 폴더 최상단에 압축 해제합니다.
2. 이후에는 `JINSHU_KO_AUTO.bat`으로 게임을 실행합니다.
3. 실행기가 한국어 패치의 최신 버전을 자동으로 확인하고 안전하게 적용합니다.

## 안전 기능

- 다운로드 파일별 SHA-256 무결성 검사
- 인터넷 연결 실패 시 설치된 패치로 오프라인 실행
- 게임 스크립트 수정 전 자동 백업
- 예상한 코드 구조가 없으면 원본을 보존하고 적용 중단
- 게임 공식 업데이트 후 한국어 연결 자동 복구

게임 원본 파일은 이 저장소에 포함하지 않습니다.
